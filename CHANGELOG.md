# Changelog

## 0.0.1 — 2026-10-23

- Object-based components and classic-script framework bundles with preserved public names.
- Explicit state subscriptions, reactive DOM bindings, safe plain text, conditional regions, and keyed lists.
- Mount-owned cleanup for children, event handlers, subscriptions, requests, and timers.
- Parameterized routes and retained route shells with cancellation of obsolete navigation.
- Typed requests, observable resources, polling, caching, and configurable state persistence.
- Standalone fixture-backed examples under `Example/`, served by `npm run dev` without a backend or build step.
- Framework-only packaging, readable and minified builds, source maps, and a tag-triggered GitHub release workflow.
